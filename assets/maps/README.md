# World map data

`natural-earth-countries.js` is a compact GeoJSON feature collection containing Natural Earth 1:50m Admin 0 country boundaries. Natural Earth vector data is public domain. It is loaded as a local script so Leaflet can render it when `index.html` is opened with `file://` without fetching map tiles.

Source: https://github.com/nvkelso/natural-earth-vector/tree/master/geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/
